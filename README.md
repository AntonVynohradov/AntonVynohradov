## About

I design and build reliable, secure embedded products end to end: firmware, BSPs and drivers, RTOS and Embedded Linux platforms, hardware bring-up, and the security and compliance work needed to ship them.

- 🔧 **Embedded software**: bare-metal, RTOS and Linux firmware in C/C++, built to be maintained for years
- 🧩 **BSP & drivers**: bootloaders, Zephyr drivers, Linux kernel work for MCUs, SoCs and SoC FPGAs
- 🔐 **Security & compliance**: secure boot, threat modelling, MISRA C/C++, EU Cyber Resilience Act (CRA) readiness
- 🏭 **Industries**: industrial IoT, automotive, robotics, medical and consumer electronics
- 📍 Based in **Poland**, working remotely worldwide
